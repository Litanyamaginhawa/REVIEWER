Binary Conversions

Binary → Octal

Easy rule: 3 bits = 1 octal digit.

Group from the right in 3s. If the left group is short, add zeros on the left.

Binary → Decimal

Easy rule: Multiply by powers of 2, then add.

Start with 2⁰ at the rightmost bit, then 2¹, 2², 2³...

Binary → Hexadecimal

Easy rule: 4 bits = 1 hex digit.

Group from the right in 4s and use the hex table for 0–F.

Decimal Conversions

Decimal → Binary

Easy rule: Divide by 2. Keep remainders. Read them bottom → top.

Decimal → Octal

Easy rule: Divide by 8. Read remainders bottom → top.

83 ÷ 8 = 10 r3 10 ÷ 8 = 1 r2 1 ÷ 8 = 0 r1 Answer: 123₈

Decimal → Hexadecimal

Easy rule: Divide by 16. Remainders 10–15 become A–F.

47 ÷ 16 = 2 r15 = F 2 ÷ 16 = 0 r2 Answer: 2F₁₆

Octal Conversions

Octal → Binary

Each octal digit = exactly 3 bits.

57₈ 5 → 101 7 → 111 = 101111₂

Octal → Decimal

Multiply by powers of 8 + add.

157₈ = 1×8² + 5×8¹ + 7×8⁰ = 64+40+7 = 111₁₀

Octal → Hexadecimal

Use Binary as the bridge.

57₈ → 101111₂ → 0010 1111₂ → 2F₁₆

Hexadecimal Conversions

Hexadecimal → Binary

Each hex digit = exactly 4 bits.

B6₁₆ B → 1011 6 → 0110 = 10110110₂

Hexadecimal → Octal

Hex → Binary → Octal.

2F₁₆ → 00101111₂ → 000|101|111 → 57₈

Hexadecimal → Decimal

Multiply by powers of 16 + add.

2F₁₆ = 2×16 + F(15) = 32+15 = 47₁₀

Super Easy Cheat Rules

TO DECIMAL → Multiply by powers of the starting base, then ADD.
FROM DECIMAL → Divide repeatedly by the target base; read remainders BOTTOM → TOP.
BINARY ↔ OCTAL → 3-bit groups.
BINARY ↔ HEX → 4-bit groups.
OCTAL ↔ HEX → go through BINARY.

Fast Rules

Any base → Decimal: multiply by powers of the base, then add.
Decimal → Any base: repeated division; read remainders bottom → top.
Binary ↔ Octal: groups of 3 bits.
Binary ↔ Hex: groups of 4 bits.
Octal ↔ Hex: go through Binary.
